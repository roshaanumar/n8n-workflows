# 🚀 n8n Workflow Collection

A curated collection of **n8n automation workflows** created while completing the **n8n Quickstart Course**. This repository demonstrates practical workflow automation, API integrations, AI-powered workflows, data processing, and business automation using n8n.

---

## 📌 About

This repository contains a series of hands-on workflows covering real-world automation scenarios. Each workflow is organized into its own folder with:

- 📄 Workflow JSON file
- 🖼 Workflow screenshot
- 📘 Dedicated README with explanation

The collection showcases automation techniques ranging from simple data transformations to AI-powered customer service agents.

## 🚀 Getting Started

1. Clone this repository

```bash
git clone https://github.com/roshaanumar/n8n-workflows.git
```

2. Open n8n.

3. Import any `.json` workflow into your n8n instance.

4. Configure the required credentials (API keys, webhooks, etc.).

5. Execute the workflow.
