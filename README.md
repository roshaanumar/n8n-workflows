# n8n Workflows Collection

A collection of workflow automation projects built while learning **n8n**. Each workflow demonstrates a different automation concept, including API integrations, data transformation, image processing, date manipulation, and file generation.

## Repository Structure

| Folder | Description |
|--------|-------------|
| 01-Hacker-News-Workflow | Retrieves and processes Hacker News articles. |
| 02-Sales-Data-Workflow | Fetches customer sales data and generates summary information. |
| 03-Customer-Summary-Workflow | Retrieves customer data and creates a summarized output. |
| 04-Get-Blog-Title-Workflow | Extracts the title of a webpage using HTML parsing. |
| 05-JSON-to-XML-Workflow | Converts JSON data into XML format. |
| 06-Manipulate-Dates-Workflow | Performs date calculations and conditional date manipulation. |
| 07-Get-and-Edit-Images-Workflow | Downloads an image and applies image transformations. |
| 08-Data-into-CSV-Workflow | Retrieves API data and converts it into a CSV file. |

## Technologies Used

- n8n
- REST APIs
- HTTP Request Node
- HTML Node
- XML Node
- Code Node
- Edit Fields Node
- Date & Time Node
- IF Node
- Convert to File Node
- Image Node

## How to Use

1. Clone this repository.
2. Open your n8n instance.
3. Import any `.json` workflow.
4. Configure credentials if required.
5. Execute the workflow.
